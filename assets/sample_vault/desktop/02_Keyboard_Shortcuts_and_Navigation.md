# Keyboard Shortcuts & Navigation

Maximize your productivity in noteflow using desktop hotkeys and rapid navigation controls.

## Essential Hotkeys

| Action | Linux / Windows | macOS | Description |
|---|---|---|---|
| **Spotlight Search** | `Ctrl+K` | `Cmd+K` | Fast fuzzy search across notes, headings & drawings |
| **Reading View** | `Ctrl+1` | `Cmd+1` | View entire active folder as a continuous roll |
| **Edit View** | `Ctrl+2` | `Cmd+2` | Dual-pane editor with live synchronized preview |
| **Toggle File Explorer** | `Ctrl+B` | `Cmd+B` | Show/hide left workspace tree sidebar |
| **Toggle Outline Inspector**| `Ctrl+J` | `Cmd+J` | Show/hide right outline and topic tags panel |
| **Open Vault Folder** | `Ctrl+O` | `Cmd+O` | Open any local directory on disk as a vault |
| **Create New Vault** | `Ctrl+N` | `Cmd+N` | Initialize a fresh workspace directory |
| **Commit Creation/Rename** | `Enter` | `Return` | Confirm inline file or folder rename |
| **Cancel Creation/Rename** | `Escape` | `Escape` | Dismiss inline creation without changes |

@@info #mark_shortcuts_01 title="Spotlight Search (Ctrl+K)"
Spotlight search parses all markdown headers, tags, file titles, and embedded drawing names. Use arrow keys to navigate and press Enter to jump straight to that line in Edit mode!
@@/info

## Window & Workspace Panels

1. **Left Sidebar**: 
   - **WORKSPACE TREE**: Full directory hierarchy with context menu (Right-click to rename, delete, or create).
   - **TOPICS PANEL**: Live counts of all tags (`@@imp`, `@@info`, `@@todo`, `@@review`) with one-click filtering.
2. **Right Sidebar**:
   - **OUTLINE**: Filterable heading tree. Drag any node up or down to reorder the content in the underlying file!
   - **PROPERTIES**: Frontmatter and tag inspection.
