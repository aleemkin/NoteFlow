# Starting Your Own Vault

Setting up your personal knowledge workspace in noteflow takes only seconds.

## 1. Choose or Create a Directory

noteflow turns any local folder into an interactive knowledge vault:
- Create a new empty folder anywhere on your computer (e.g. `~/Documents/Notes`).
- Or point to an existing folder with Markdown files, documentation, or Git repos.

## 2. Open in noteflow

- Press `Ctrl+O` / `Cmd+O` at any time.
- Or click the folder icon in the top WindowChrome header.
- Select your directory in the native file picker.

@@info #mark_vault_setup_01 title="Auto-Restore on Launch"
noteflow automatically remembers the last opened vault. When you reopen the application, your workspace is restored instantly right where you left off.
@@/info

## 3. Working with Git & External Tools

Because noteflow saves pure Markdown and standard Excalidraw files:
- Initialize a Git repository inside your vault: `git init`
- Commit your notes and drawings: `git commit -am "Daily notes"`
- Sync via GitHub, GitLab, Syncthing, or your private server.
