# Dual-Pane Split Editor

Press `Ctrl+2` or click the Editor button in the top bar to enter Edit View.

## Parallel Live Editing

- **Left Pane (Source Markdown)**: Clean raw text editing with syntax highlighting, automatic line numbers, and indentation.
- **Right Pane (Synchronized Preview)**: Renders typography, tables, checklists, callouts, and embedded diagrams in real time.
- **Debounced Instant Auto-Save**: An indicator at the top right of the editor reflects save state (`Saved`, `Saving...`). No manual saves required.

@@imp #mark_guide_editor_01 title="Instant Formatting Toolbar"
Use the floating formatting toolbar above the editor to insert bold, italics, code blocks, tables, callout blocks (`@@imp`, `@@info`), or drawing references with one click!
