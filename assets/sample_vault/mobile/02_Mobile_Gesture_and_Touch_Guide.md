# Mobile Gesture & Touch Guide

noteflow Mobile is engineered for intuitive one-handed navigation and fluid touch gestures.

## Core Touch Gestures

| Gesture | Screen / Location | Action |
|---|---|---|
| **Horizontal Swipe** | Editor Tab | Toggle between Markdown editor and rendered preview |
| **Floating Action Button (FAB +)** | Notes Tab (Bottom-Right) | Instantly create a new note in active folder |
| **Tap ☰ Menu** | Top-Left App Bar | Open Left Drawer (File Explorer & Folder Tree) |
| **Tap Outline Icon** | Top-Right App Bar | Open Right Drawer (Section Jumper & Topic Filter) |
| **Long-Press Text** | Notes Reading Roll | Open Floating Toolbar (Tag @@imp, @@info, insert drawing) |
| **Pinch-to-Zoom** | Canvas Tab | Zoom in or out on Excalidraw vector canvas |
| **Two-Finger Drag** | Canvas Tab | Pan around the infinite vector canvas |

@@info #mark_mobile_gestures_01 title="Floating Selection Toolbar"
Select any paragraph in the Notes tab to reveal the floating action toolbar. You can mark text as Important (`@@imp`), Reference (`@@info`), or insert a drawing block above or below.
@@/info
