# Mobile Writing & Tags

Write clean, structured Markdown on mobile with rapid formatting buttons and semantic tags.

## Mobile Markdown Checklist

- [x] Use `- [ ]` for instant interactive checklists
- [x] Wrap with `**bold**` or `*italic*` for emphasis
- [x] Use standard `#`, `##`, `###` for headings
- [ ] Add drawing diagrams with `@@drawing ./diagram.excalidraw`

## Mobile Semantic Tags

Tagging blocks allows you to filter the continuous roll from the right drawer with a single tap:

### Priority Highlights (`@@imp`)
@@imp #mark_mobile_tags_01 title="Immediate Attention"
Critical reminders, urgency items, or key decisions.
@@/imp

### Reference Notes (`@@info`)
@@info #mark_mobile_tags_02 title="Device Specifications"
Notes stay entirely in local app storage without background telemetry.
@@/info

### Quick Action Item (`@@todo`)
@@todo #mark_mobile_tags_03 title="Next Action"
Tasks to follow up on during the day.
@@/todo

### Single-Line Shorthand
@@todo> Buy groceries on the way home!
