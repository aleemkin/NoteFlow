# Managing Vaults on Device

Learn how noteflow organizes vaults and files in your device storage.

## Device Storage Location

- On Android and iOS, vaults are stored safely in your app documents directory (e.g. `Documents/Sample Vault`).
- You can create multiple separate workspaces for personal notes, work logs, or study materials.

## The Vault Tab

Switch to the **Vault** tab in the bottom bar to:
1. View metrics (note counts, drawings, directories).
2. Tap **Open Local Vault** to select another folder on device.
3. Tap **Create New Vault** to initialize a clean workspace.
4. Quickly reopen recent vaults.

@@info #mark_vault_mobile_01 title="Export & Backup"
Because your files are standard Markdown and Excalidraw files, you can back them up using cloud storage, USB file transfer, or SD card backup tools at any time.
@@/info
