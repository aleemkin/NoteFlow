# Quick Start & Shortcuts

Get the most out of noteflow with essential keyboard shortcuts and navigation tips.

## Essential Shortcuts

| Action | Shortcut |
| --- | --- |
| Spotlight Search | `Ctrl+K` / `Cmd+K` |
| Reading View (Continuous Roll) | `Ctrl+1` |
| Edit View (Split & Auto-Save) | `Ctrl+2` |
| Toggle Left Sidebar | `Ctrl+B` |
| Open Vault Folder | `Ctrl+O` |
| Commit Inline Rename / Create | `Enter` |
| Cancel Inline Rename / Create | `Escape` |

## Topics & Callout Marks

Highlight blocks using custom semantic tags:

- `@@imp`: High priority notes and critical warnings
- `@@info`: Informational references and technical specifications
- `@@todo`: Action items and tasks
- `@@review`: Content flagged for editorial or team review
- `@@architecture`: System design and architectural decisions
- `@@drawing`: Embedded vector drawings
- `@@view`: Cross-note block previews
